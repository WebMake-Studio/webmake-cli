## Supported versions

Only the latest 2.x release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private
"Report a vulnerability" button (Security tab of the repository), or contact the maintainer by email.
You will get an answer within 7 days.

WebMake CLI is a **development** server: do not expose it to the public internet.
