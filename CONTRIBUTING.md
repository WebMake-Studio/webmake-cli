# Contributing to WebMake CLI

Copyright (c) 2026 Rafael ISTE (FarTekTV) - MIT License

1. Fork the repository and create a branch (`git checkout -b feat/my-change`).
2. Requirements: Node.js >= 18.17. **No runtime dependency** may be added.
3. Run `npm test` (must pass on Windows, macOS and Linux; CI checks all three).
4. Keep source files free of comments except the one-line copyright header.
5. Update `CHANGELOG.md` and the README if behavior changes.
6. Open a pull request using the template.
